# 到底要怎样的才能开心下去

> 2026-08-11|liutao|life
>
> 我觉得最近的我好像变了，怎么办，心也不见了。

## 时常迷茫

我也不知道为什么，最近的我总是异常的迷茫，或许是工作，或许是生活，有点乱了。到底该如何下去是好，有一份正常的工作，正常的生活，或许会很好，到底在追求什么呢，我想应该是想家了。

艰难打怪升级，好像没有了以前的心气了，也不知道留下的到底是什么，我想要给自己定一个目标，whatever。回忆从前，老想着自己弄丢的冠军要努力的拿回来，只是为了证明自己丢的东西要亲手拿回来，但是现在，我觉得是一个开放性的试题，我有好多想做的，就像这个网站，重构了很多版本，也不记得到底是V几了，git是有记录的，我把大学那版的仓库清了，重构了一个放进去。

最近跟一些学长聊天，我学到了很多的东西，跟他们聊起工作中遇到的问题，他们以他们的经验告诉我应该怎么做，我也有时候常常在想，到底要经历多少，才能真正的读懂生活。25岁了，我想我应该知道我要干什么了，这一路走来，我想有很多的不易，迷茫，焦虑，痛苦，当我再一次面对很多事情的时候，我发现18岁的我，那时候我在干什么，从一个B班垫底的小坏蛋，变成了老师口中那个很牛逼的学生，那时候很多人见到我，说的很多的话是，你就是那个刘涛，牛的，好像那时候被人见到就开始介绍，“你知道吗，这个就是那个刘涛，从倒数考到前三的人“，每每回想，我觉得我怀恋的是哪个时候的自己，虽然那一路走的很痛苦，很抑郁，但是我一直想着的都是我想要震惊所有人，maybe,我也许做到了那个时间段我要实现的梦，但是对于结果，我并不是看的那么重，心心念念的还是那两年的日夜。我想调整了，见了很多的人，老师，学长，朋友，人生吗，车到山前必有路，好好过好每一天，把每天都过的有意义，按照自己的想法一步一步去做，照顾好自己，有个好身体。
